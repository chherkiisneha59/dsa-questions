# DSA Questions in Java

This repository contains various Java programs and solutions to Data Structures and Algorithms (DSA) questions. It includes solutions to common programming problems, pattern printing, array manipulations, and basic mathematical problems.

## Contents
- Basic Java programs (loops, conditionals, math functions)
- Array manipulation and logic building
- Pattern printing solutions
- HackerRank/Striver SDE Sheet practice problems (and similar problems)

## Usage
Compile and run the `.java` files using the standard `javac` and `java` commands.
```bash
javac <filename>.java
java <filename>
```
